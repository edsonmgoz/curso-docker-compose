# Changelog

## [Unreleased]

### Added

- Sitio con Astro Starlight 0.42.10, en español, con búsqueda, modo claro y oscuro, y despliegue en
  GitHub Pages mediante GitHub Actions.
- Portada con ilustración del proyecto del curso y ruta de las diez sesiones.
- Guía de instalación para Windows con WSL 2, macOS y Linux, con pestañas sincronizadas por sistema
  operativo.
- Verificación del entorno, con inicio de sesión en Docker Hub y descarga previa de imágenes.
- Calendario, páginas de las diez sesiones con su temario, proyecto y comunidad.
- Paleta propia para tarjetas, avisos y etiquetas, imagen Open Graph y página 404.
- Animaciones sutiles solo con CSS, desactivadas si el sistema pide reducir movimiento: transición
  entre páginas, entrada única de la ilustración de la portada, aparición de la ruta de sesiones al
  hacer scroll y hover en las tarjetas enlazadas.
