## Discord

El curso tiene un canal privado de Discord para consultas entre clases, soporte adicional y contacto
directo con el docente. La invitación se envía por correo a cada participante inscrito; no se
publica en este sitio para mantener el canal reservado a quienes cursan el programa.

Para que una consulta se resuelva rápido conviene incluir:

- el sistema operativo y el procesador (por ejemplo, Windows 11 con WSL, o macOS con Apple M2);
- el comando exacto que se ejecutó;
- el mensaje de error completo, copiado como texto y no como captura.

## Grabaciones

La grabación de cada clase queda disponible en la plataforma virtual de la universidad.
